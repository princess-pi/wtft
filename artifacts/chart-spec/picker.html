Chart picker

The chart lines below come from wtft's own buildWtftLines, bundled for the browser and fed a fake session; the column ruler above them and the line count below are this page's. The command line is read by wtft's own parseWtftCliArgs. Changing a control rewrites the command line from the controls, so a typed flag with no control is dropped. The title's timeline strip follows your clock. Terminal width is not a flag: the CLI takes it from the terminal.
