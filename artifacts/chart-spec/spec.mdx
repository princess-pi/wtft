# Chart spec

`buildWtftLines` bins a session's interactions and hands the bins, newest first, to `renderWtftChart`, which draws the chart lines. `getBinInfo` labels one interaction. One cell is one category. The columns, the cache-miss line, the date line, the title with its timeline strip, and the legend are part of that draw.

This page is the picture of that chart, and the picker is the chart. The picker bundles wtft's own `buildWtftLines` and `parseWtftCliArgs` for the browser and runs them on a fake session. Every control is a chart flag or the terminal's width. Type a flag into the command line and the controls follow. The four blocks below are the four presets under a pinned clock, so a reader without the picker still sees them.

## The fake session

Three working days of one session, Sep-24, Sep-25 and Sep-26. Each interaction is shaped as a tag file returns it, with `_cat` set, so the classifier's file, command and text inputs are not needed. Cost comes from the same `calculateClaudeCost` the parser calls. A turn after a gap of 12 minutes or more, and each day's first turn, is a cache miss and is classed `overhead`.

The model picks the timeline strip. `claude-sonnet-5-5` has no surge schedule, so the strip is one colour. `deepseek-v4-pro` has one, so the strip draws its surge hours in orange, the surge badge appears when the real clock is inside a window, and a turn billed at the surge rate makes its row orange, with a bolt when the columns have their full two-space gap.

## Encoding law

A cell is one category.

- Color is the category. The glyph is `█`.
- On a running-total token bar, recency is the second axis, and it uses the glyph. `▃` is carryover. `▇` is new this bin. Both glyphs are that one category.
- Recency applies to a token running total. An incremental bar is entirely new, so recency stays off. A cost bar stays `█`.
- A scatter column that two categories round onto keeps the larger cost. The cell stays one category. An equal cost keeps the earlier category in the category order. Scatter is the cost bucket bar. A token bucket bar is a stack of `█` when that bin has token counts.

## Rows

Each row prints the bin label, incremental cost, total cost so far, incremental tokens, total tokens so far, and the bar.

- `--cost` and `-C` choose the cost bar. `--tokens` and `--by-model` choose the token bar. With neither, the bar is cost, unless the config sets tokens.
- `--cumulative` and `-c`, or `--bucket` and `-b`, choose a running total versus this bin. With neither, the mode is cumulative, unless the config sets it.
- `--no-cost` hides the cost pair. `--no-tokens` hides the token pair.
- The layout width is at least 40. The bar is what remains after the label area and the scale's reserved cells: 3 for cost, 5 for tokens. Under 15 cells the token pair goes first, then the cost pair.
- The label area is compacted when it is more than a quarter of the width. `docs/spec-362-compact-label-columns.md` has the five steps. On this session the first step starts under 154 columns.
- A positive amount under one cent uses four decimal places.
- A cumulative cost bar is `round(total / scale × bar)` cells. The scale is the session total for a running total, and the largest displayed bin for a bucket. A cost scale of 0 or less becomes 1; above 20 it ceils to a multiple of 5; otherwise it ceils to an integer. A token scale ceils to a multiple of 1000.
- A scatter mark sits at `round(cost / scale × (bar − 1))`.
- A token bar draws one `$` when web cost is positive and web tokens are 0, and the bar still has a free cell.
- The monotonic clamp is on the cost running-total bar. A category that already holds a cell does not shrink below that count. A token running total does not use it.

## Lines between rows

A rule inserts one line on the older side of the boundary, which is where the cache-miss line sits.

- Cache miss: the line reads `Cache Miss`, on the older side of the missed row. A miss on the oldest row still draws the line under it. When a miss and a date change share a boundary, the miss line comes first.
- Date change: the line reads the older bin's date as `Mmm-DD`, whenever the date changes. A turn interval that crosses a date still draws it.
- Padding: the CLI pads the chart out to `-l` rows with a dash row. The Pi widget does not. `docs/spec-264-pad-rows.md`.

## Lines above and below

- Title: `💸 WTF Tokens?` for cost and `🔢 WTF Tokens?` for tokens, then `...` and the last four characters of the session file name, then the timeline strip. `--no-emoji` draws `[$]` and `[#]`.
- Timeline strip: 24 hours, the moon at each end, the sun at noon, a clock face at the current hour. Surge hours are orange.
- Legend: every category, including ones with no spend in the session.
- Scale line: draws when the scale is above 0 and the bar is at least 15 cells. It carries the newest bin's date.
- A token chart ends with the glyph key and a token footer. Both charts end with a cache-hit line when the session has cache tokens.
- An "Other" warning line appears in a cost chart when Other is more than a fifth of the spend and more than $6.

## Outside the picker

- The CLI report prints more than the chart: the token summary under `--tokens`, the histogram under `--other`, and the provisional warning. The picker prints the session path line and the chart.
- `--width` is read and ignored by the CLI. The CLI takes its width from the terminal, minus `--pad` on each side. The picker's terminal slider is that width.
- The Pi widget builds the same chart from `extensions/wtft.ts`, with its own `-w` width, no padding rows, and a limit fitted under Pi's 10-line cap by `docs/spec-269-widget-fit.md`.

## Settled

- A cell is one category. https://github.com/princess-pi/wtft/pull/298
- The scale line draws when the scale is above 0 and the bar is at least 15 cells. A date line is drawn when the date changes. https://github.com/princess-pi/wtft/pull/298
- `renderWtftChart` draws the chart lines. https://github.com/princess-pi/wtft/pull/302
- All four columns are the default. `--no-cost` hides the two cost columns. `--no-tokens` hides the two token columns. https://github.com/princess-pi/wtft/pull/304
- A second painter stays unstarted. https://github.com/princess-pi/wtft/issues/285
