Parser playground

Paste Claude Code or Pi transcript lines, one JSON object per line. Each line runs through wtft's own applyControlEntry and parseEntryToInteraction, bundled for the browser; then deduplicateInteractions, classifyInteraction and splitOverheadCost run as the log parser daemon runs them. The one step missing is the claude -p fold, which reads other transcripts from disk.
