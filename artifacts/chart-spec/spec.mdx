# Chart spec

`buildWtftLines` drops duplicate interactions, bins the rest, and hands the newest `-l` bins, newest first, to `renderWtftChart`, which draws the chart lines. With no bins it returns no chart. `getBinInfo` labels one interaction. A drawn cell is one category. Everything in "Lines between rows" and "Lines above and below" is part of that draw.

This page is the picture of that chart, and the chart picker draws with the chart itself. It bundles wtft's own `buildWtftLines` and `parseWtftCliArgs` for the browser and runs them on a fake session. The step between them, from parsed flags to the chart call, is `chartLines`, the function the CLI report arm calls too. The picker draws emoji unless `--no-emoji` is given, because it has no config file to read. Each control is a wtft flag, the terminal's width, the fake session's model, or its file name, beside four preset buttons and a copy button. Type a flag into the command line and the controls follow. Changing a flag's control rewrites the command line from the controls, so a typed flag with no control is dropped. The chart picker draws under the real clock. The four blocks below are the four presets under a pinned clock, so a reader without the chart picker still sees them.

## The fake session

Three days of one session, Thursday Sep-24 to Saturday Sep-26. Each interaction is shaped as a tag file returns it, with `_cat` set, so the classifier's file, command and text inputs are not needed. Cost comes from the same `calculateClaudeCost` the parser calls, plus `calculateServerToolCost` on web turns and on every ninth code turn. A turn after a gap of 12 minutes or more, and each day's first turn, is a cache miss and is in the `overhead` category.

The model picks the timeline strip: the CLI reads the first interaction that names a model, and the Pi widget passes its current model. `claude-sonnet-5-5` has no surge schedule, so the strip is one colour. `deepseek-v4-pro` has one. Its surge hours are orange only on a day that bills surge: its schedule skips weekends, and the session's last day is a Saturday, so the strip is all green. On a live view a badge follows the strip: `⚡ SURGE Nx` (`!!` for `⚡` under `--no-emoji`) inside a window, `SURGE ENDING` in its last 20 minutes, and `SURGE APPROACHING` in the 20 minutes before one. One turn billed at the surge rate turns its whole row's label and number columns orange; the bar keeps its category colours. With the columns at their full two-space gap, a bolt, `⚡` or `!!` under `--no-emoji`, takes the gap after the first number column, or after the label when at most one column shows.

## Encoding law

A drawn cell is one category. An empty scatter column belongs to none, and one `✨` covers two cells of one category.

The category order is the `words.categories` slots in list order, then the rest in wtft's order; with no list it is wtft's order. It is the legend's order and the stack's, and every tie below goes to the earlier category in it.

- Color is the category. The glyph is `█`, `✨` on a running-total bar, or `$` on a token bar (see Rows).
- On a running-total bar, cost or tokens, recency is the second axis, and it uses the glyph. `█` is earlier bins. `✨` is this bin. Each category's segment draws its `█` run, then its `✨` run. The `✨` run's share of the segment is the category's share that is new this bin: this bin's cost over its running cost on a cost bar, this bin's tokens over its running tokens on a token bar.
- `✨` is two cells wide, so the `✨` run is an even number of cells: its share of the segment rounded to the nearest even count, at least 2 for a category with any new cost or tokens this bin, and at most the segment's cells rounded down to even. A one-cell segment draws `█`. Rounding to even, the floor of 2 and the one-cell rule each move the split by up to a cell or two, so a `█` can carry some of this bin's spend and a `✨` some of earlier bins'. Each category's cell count is set as in Rows; recency only splits it.
- A terminal draws `✨` in the emoji's own colours, whatever the foreground, so the `✨` cells carry a dark shade of the category's colour as their background: the same hue at one WCAG relative luminance for every category, `SPARKLE_BG_LUMINANCE` in `extensions/lib/wtft-chart.ts`, written as a 24-bit colour. A colour darker than that luminance is brightened to it. A channel that would pass full brightness stops there, so a saturated colour such as a caller's pure blue shifts hue and can stay below it. Palette entries 0–15 are read as fixed RGB values, not the terminal's theme. That luminance sets `✨`'s contrast, and is set to personal preference. Dimmer values, around 0.08 to 0.12, give `✨` the most contrast, but at those dimmer values the core color is lost. Initially set to 0.2 as a balance between identifying the color category and the sparkle's contrast. The 256-colour palette has no dark shade of most category hues. `--no-emoji` draws `*` in each of those cells, in the terminal's default colour on the same background.
- Recency applies to a running total. An incremental bar is entirely new, so recency stays off and a bucket bar draws no `✨`.
- A scatter column that two categories round onto keeps the larger cost. The cell stays one category. An equal cost keeps the earlier category in the category order. Scatter is the cost bucket bar. A token bucket bar is a stack of `█`, then the `$` when Rows draws one; with neither it is empty.

## Rows

Each row prints the bin label, incremental cost, total cost so far, incremental tokens, total tokens so far, and the bar.

- `--cost` and `-C` choose the cost bar. `--tokens` and `--by-model` choose the token bar. With both, cost wins in any order in the CLI; the Pi widget's `/wtft` takes the later of the two and saves it to the config. With neither, the bar is cost, unless the config sets tokens.
- `--cumulative` and `-c`, or `--bucket` and `-b`, choose a running total versus this bin. With both, the later flag wins. With neither, the mode is cumulative, unless the config sets it.
- `--no-cost` hides the cost pair. `--no-tokens` hides the token pair.
- The layout width is the terminal's width less the pad on each side, capped at 1023, and at least 40. The bar is what remains after the label area and the scale's reserved cells: 3 for cost, 5 for tokens. A token bar draws into two cells fewer than that. Under 15 cells the token pair goes first, then the cost pair.
- The label area is compacted when it is more than a quarter of the width. `docs/spec-362-compact-label-columns.md` has the five steps. On this session, with all four columns, the first step starts at 173 terminal columns and the second at 153.
- A positive amount under one cent uses four decimal places.
- A cumulative cost bar is `round(total / scale × bar)` cells, split among categories in four steps, oldest displayed row first:
  - Floor: each category gets the floor of its `cost / scale × cells`.
  - Monotonic clamp: a category that held a cell on the next-older displayed row gets at least that row's count. The oldest displayed row is not clamped: no row is compared with an older bin the limit leaves out.
  - Trim: while the clamped counts exceed the bar's cells, the category that grew most over that older row, among those holding a cell, loses one. A trim can take a category below its count on the older row.
  - Leftover: cells still free go one at a time to the category furthest below its share of the bin, `cost / total × cells`. A bin with no cost gets none.
- A token bar gives each category `round(total / scale × (bar − 2) × share)` cells, cut off at the bar's end. The scale is the session total for a running total, and the largest displayed bin in bucket mode. The cost total includes server-tool cost, and the token total counts every interaction, displayed or not. A cost scale of 0 or less becomes 1; above 20 it ceils to a multiple of 5; otherwise it ceils to an integer. A token scale ceils to a multiple of 1000.
- A scatter mark sits at `round(cost / scale × (bar − 1))`.
- A token bar draws one `$` after its segments, in the web category's colour, when the bin's web cost is positive, its web tokens are 0, and the bar still has a free cell. Server-tool cost is web cost whatever turn it comes from, so the `$` can start on a non-web turn, and a web turn with no tokens does not end it. On a running total both are running totals, so the `$` shows until the web category first has tokens. The `$` has no recency split. It is `words.currency`, or `$` when that is empty.
- The monotonic clamp and the trim are on the cost running-total bar only. A token running total does not use them.

## Lines between rows

A rule inserts one line on the older side of the boundary, which is where the cache-miss line sits.

- Cache miss: the line is `── Cache Miss ──` run out to the scale's reserve, with `┼` at the scale's five ticks, on the older side of the missed row. The date line has the same shape. A miss on the oldest row still draws the line under it. When a miss and a date change share a boundary, the miss line comes first.
- Date change: the line reads the older bin's date as `Mmm-DD`, between two bins whose dates differ. A turn bin's date is its newest turn's, so a turn bin that spans midnight draws no line inside itself.
- Padding: the CLI pads the chart out to the limit (`-l`, else the config, else 17, at most 1000), counting bin rows only, with rows of grey dashes in the label and number columns and no bar. `--watch` pads to the smaller of the limit and the terminal's rows, and drops padding first when the frame is too tall. The Pi widget does not pad. `docs/spec-264-pad-rows.md`.

## Lines above and below

- Title: `words.title`, else `💸 WTF Tokens?` for cost and `🔢 WTF Tokens?` for tokens, then `...` and the last four characters of the session file name with a trailing `.jsonl` removed (nothing with no session file), then the timeline strip. `--no-emoji` draws `[$]` and `[#]`, which `words.title` replaces too, and ASCII in the strip: `|` for a moon, `*` for the sun, `@` for the clock and `!!` for the bolt. With neither `--emoji` nor `--no-emoji`, the CLI reads the config.
- Timeline strip: 24 hours, green, the marked hour bold. A moon at each end shows the phase at that end's midnight, so the two can differ. The sun is an extra cell between 11 and 12, in hour 12's colour. A clock face marks the hour: the current one on a live view, else the newest interaction's. Surge hours are orange, and the surge badge follows the closing moon.
- Legend: every category in wtft's order, including ones with no spend in the session. With `words.categories`, the listed entries that carry a label, in list order, each its `char` (else `█`) in its `fg` and then its label. An entry whose slot is not one of the 14, or repeats an earlier entry's slot, is dropped. A list with no labelled entry left, an empty list included, prints a blank legend line.
- Scale line: draws when the scale is above 0 and the bar is at least 15 cells. It carries the newest bin's date, which the first scale label can overwrite on a narrow label area, and five reverse-video labels at 0, ¼, ½, ¾ and full scale; a label that would overlap an earlier one is dropped, and token labels take one decimal place.
- Every running-total chart, cost or tokens, prints the glyph key after its rows: `█ earlier bins  ✨ this bin`, with `**` in place of `✨` under `--no-emoji`, whether or not a row drew a `✨`. The key's `█` is white and the rest grey; its `✨` sits on the `█`'s hue at the luminance every `✨` background gets, as a bar draws it. `words.key.earlier` and `words.key.thisBin` replace the two phrases. When a token chart draws a `$`, a `$ = cost-only (web tools)` note follows the key, or stands alone in a bucket chart; `words.key.costOnly` replaces the text after `$ = `. A bucket chart with no `$` prints no key line. A token chart then prints its token footer when there is one. Both charts end with a cache-hit line when the session has any cache-read, cache-write or input tokens, so `CH: 0%` prints on a session with no cache.
- An "Other" warning line, bold yellow and led by `⚠️` (`!!` under `--no-emoji`), appears in a cost chart, after the padding rows and before the key, when Other is more than a fifth of the spend and more than $6. Other's figure leaves out server-tool cost; the spend it is compared with includes it.

## Outside the picker

- The CLI report prints the session path line and the chart, and more: the token summary when the last of `--tokens`, `--by-model`, `--cost` and `-C` is a token flag (so `--cost --tokens` prints it under a cost chart, and a token chart from the config prints none), the histogram under `--other` or `-o`, the provisional warning, and warnings on stderr. The chart picker prints the session path line and the chart.
- `--width` is read and ignored by the CLI. The CLI takes its width from the terminal, minus `--pad` on each side (1 by default, at most half the terminal less one). The chart picker's terminal slider, 40 to 240, is the terminal's width, before the pad.
- The Pi widget builds the same chart from `extensions/wtft.ts`, with its own width (`-w`, else the terminal's width less 2; at most 240), which the terminal's width then caps, no padding rows, and a limit fitted under Pi's 10-line cap by `docs/spec-269-widget-fit.md`.
